This workbench is a live digital twin of your 433 MHz ESP32 + LoRa mesh handheld firmware (SSOT v3.0). Every node runs the exact 12-state OLED interface, controlled-flooding router, and embedded 192.168.4.1 web server.

STEP 1 — Operate the OLED Handset (Left Dock)
Select any node (N01–N08) and use NEXT, SELECT, and RED / SOS to open MESH NET, send presets, or view RESCUE radar.
STEP 2 — Pan, Zoom & Test Multi-Hop Routing (Center Map)
Drag empty canvas to pan, scroll wheel to zoom, drag nodes apart, or place RF blockers (+ Blocker) between N01 and N04 to watch N02/N03 automatically relay packets ([SENT] → [RELAY] → [ACK]).
STEP 3 — Inspect 44-Byte Frames & Web Portal (Right Dock)
Switch tabs on the right to dispatch messages from 192.168.4.1, inspect the 44-byte binary hex & FNV-1a MAC tag, or check pairwise link budgets.

1. Controlled Flooding & Overhear Suppression

Each node caches the last 32 (srcId, msgId) pairs. When forwarding a packet with ttl > 0, nodes wait a randomized 90–280 ms jitter window. If another neighbor rebroadcasts the same packet first, the node cancels its redundant relay to save airtime.

2. Dual-Mode Rescue Radar (GPS Vector vs. Indoor RSSI)

Open RESCUE on the OLED. When both local and target nodes have NEO-6M GPS attached, the radar computes exact Haversine distance and compass bearing. If either unit has GPS detached, it automatically switches to a 28-sample RSSI sparkline and path-loss distance estimator.

3. Silent Light Sleep Wakeup

Toggle Light Sleep on a node (0.8 mA). When another node opens MESH NET or sends a multi-hop message, the sleeping node wakes via DIO0, replies/relays silently without lighting its OLED, and returns to sleep.
